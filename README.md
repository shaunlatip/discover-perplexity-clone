# Perplexity Discover Clone

A UI clone of Perplexity's Discover feed built with Next.js and Tailwind CSS. This project was created as a styling exercise to practice modern UI implementation using Tailwind CSS.

![Perplexity Discover Clone Screenshot](screenshot.png)

## About

This is a practice project that recreates the UI of Perplexity's Discover feed. It features:
- 🎯 Category-based content filtering
- 🎨 Responsive card layouts
- 🌓 Dark mode design
- 📱 Mobile-friendly interface
- 🔄 Smooth hover animations

## Tech Stack

- **Framework:** Next.js 14
- **Styling:** Tailwind CSS
- **Icons:** Heroicons
- **Images:** Picsum Photos (placeholders)
- **Avatars:** DiceBear API

## Getting Started

```bash
# Clone the repository
git clone https://github.com/yourusername/perplexity-discover-clone.git

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the project.
